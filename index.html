読唇ワープロ・五十音対応

五十音の文字を選び、文章にして口形カードを再生する試作アプリ

1. 五十音から文字を選んで入力

あ行からわ行、および「ん」までの基本かな46字に対応します。口形図は母音ごとの簡略見本で、子音の違いや実際の発話を正確に表すものではありません。

2. 文章ワープロ

口形パラパラ漫画

「口形画像を並べる」を押すと、ここで順番に再生できます。
0 / 0 コマ

基本かな46字は、母音に対応する口形見本と一緒にコマ表示します。句読点・漢字・小文字などは文字カードになります。実際の発話映像の解析ではありません。

3. カメラ確認（試作）

カメラ映像を表示する機能です。現在の版はAIによる自動読唇を行いません。6つの口形画像だけでは、連続した日本語の文章を自動判定できません。

4. 使い方

  1. 口形の見本を確認します。
  2. 該当する文字を選ぶと、文章欄に追加されます。
  3. 文章欄はキーボードで修正できます。
  4. 「読み上げ」で入力文を音声確認できます（対応ブラウザのみ）。
